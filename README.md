# ESCAPE PROTOCOL

### Uma experiência interativa de exploração baseada em grafos e algoritmos de busca.

---

## 1. Sobre o projeto

<p align="justify">
O Escape Protocol é um jogo interativo desenvolvido pela equipe CodeNova Studio, como atividade acadêmica da disciplina de Algoritmos e Estrutura de Dados III.
</p>

<p align="justify">
Ambientado no cenário fictício Complexo Orion, o jogo propõe a exploração de diferentes salas conectadas por passagens, utilizando conceitos de grafos para representar os ambientes e suas relações.
</p>

<p align="justify">
A proposta combina programação e interatividade para demonstrar, de maneira visual, o funcionamento do algoritmo de Busca em Profundidade (DFS – Depth-First Search), aproximando os conceitos teóricos de uma aplicação prática.
</p>

## 2. Objetivo do projeto

<p align="justify">
Desenvolver uma aplicação interativa que demonstre a utilização da estrutura de dados grafo e o funcionamento do algoritmo de Busca em Profundidade (DFS – <em>Depth-First Search</em>), proporcionando uma representação visual do processo de exploração de ambientes conectados.
</p>

<p align="justify">
O projeto também busca demonstrar conceitos como visitação de vértices, recursividade, identificação de caminhos e tratamento de conexões com restrições de acesso, relacionando os conhecimentos estudados na disciplina à construção de uma solução computacional.
</p>

## 3. Conceitos e fundamentos técnicos

<p align="justify">
O desenvolvimento do Escape Protocol envolve conceitos de algoritmos e estruturas de dados que constituem a base lógica da aplicação.
</p>

- **Grafos:** representação dos ambientes e suas conexões.
- **Lista de adjacência:** organização das relações entre os vértices.
- **Busca em Profundidade (DFS):** exploração dos caminhos disponíveis.
- **Recursividade:** execução sucessiva das etapas de busca.
- **Backtracking:** retorno a vértices anteriores durante a exploração.

## 4. Dinâmica da aplicação

<p align="justify">
A proposta do jogo é ambientada no Complexo Orion, onde os ambientes são organizados por meio de conexões que formam a estrutura do grafo.
</p>

<p align="justify">
Durante a exploração, o algoritmo DFS percorre os caminhos disponíveis, registra os ambientes visitados e identifica conexões que apresentam restrições de acesso. A progressão também considera objetivos relacionados à obtenção de itens e à ativação de recursos necessários para liberar determinadas passagens.
</p>

<p align="justify">
A representação visual desses elementos busca facilitar a compreensão do percurso realizado pelo algoritmo e demonstrar como os conceitos de grafos podem ser aplicados em uma situação prática.
</p>
